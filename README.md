# WebLAV

パソコンの中のファイルを、同じネットワーク (LAN) にいるスマートフォンやタブレットのブラウザで見られるようにするアプリ。
パソコンでは通知領域 (macOS はメニューバー) に常駐し、見る側の端末にはアプリを入れない。

## できること

- 音声を再生する (画面の下に出るプレイヤーで、続けて再生・前後の曲・10秒戻す・進む)
- 画像・PDF・動画・テキストを見る
- ファイルをアップロードして見せる
- 外部サイトへのリンクを並べる
- 見せる相手を、誰でも・ログインした人だけ・自分だけに分ける
- 決まった形で名前を付けたファイルの集まり (年度・回などを含むファイル名) を、名前から読み取った項目で絞り込んで見せる (アーカイブ)
- 画面の言語は日本語と英語

見せるのは、管理画面でコンテンツとして登録したもの (「公開できるフォルダ」の中から選んだフォルダ、アップロードしたファイル、リンク) だけ。

## 要るもの

- 動かすパソコン: Windows 10 (1809) 以降
- 見る側: 同じ LAN にいる端末のブラウザ
- LAN の外からは使えない。インターネットに公開するしくみは持たない。

## 入れ方・使い方

- Windows は Microsoft Store で配る。macOS 版は配っていない。
- 使い方は、アプリの中のマニュアル (通知領域のアイコンの「マニュアル」) にある。原稿は `docs/manual/`。

## Free と Pro

Free では、管理者・編集者・コンテンツの数に上限がある。Pro にすると上限が外れる。上限と買い方は管理画面の「サイト設定」の「Pro」に出る。
