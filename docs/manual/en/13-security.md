# Use WebLAV safely

- Use WebLAV on a network where only people you know connect, such as at home or in an office. Do not use it on public Wi-Fi or expose it to the internet.
- On Windows, do not set public Wi-Fi networks to “Private”.
- Set items you want to limit to “Sign-in required”.
- Add only folders you are willing to share as “Shared folders”. Do not add `C:\` or your entire user folder.
- Delete accounts you no longer use.
- Do not use the same password for an administrator as for other services.

To encrypt connections, see “Use HTTPS” in [Advanced settings](14-advanced.md).
