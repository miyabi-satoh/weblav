# Use the AI features

Some features let you ask an AI from inside WebLAV.

- Have an AI suggest the axes of an archive (→ [Set up an archive](06-archive-setup.md))
- Have an AI collect web links on what you want into a group (→ “Have an AI collect links” below)

To use them, an admin registers the PC that runs WebLAV with a “WebLAV account”. Each use of the AI consumes credit from the account. Creating an account is free.

## What is sent outside

Using the AI features sends the following outside the PC. Nothing is sent unless you use them.

- What is sent
  - When you ask for axes: the names of the folders and files in that archive
  - When you ask for links: what you wrote to collect for that group
- Where it is sent: the WebLAV account server (weblav.amiiby.com), and from there Google (Gemini) and Perplexity (web search)

> If the folder or file names of an archive include personal names or the like, check first whether they may be sent.

## Register the PC

An admin does this while the PC that runs WebLAV is connected to the internet.

1. Open the “Site settings” tab in the admin pages and select “Register PC...” under “AI”
2. Read what is sent outside, then select “Agree and start registering”
3. Scan the QR code with a smartphone, or select “Open in browser”
4. On the page that opens, sign in to your WebLAV account. If you have no account, enter your email address to create one
5. Check that the confirmation code on the page that opened matches the one shown in Site settings. If it differs, do not approve
6. Approve registering the PC

After you approve, the Site settings screen switches within a few seconds and shows the account's email address and the remaining credit.

To stop partway, select “Cancel”. If you do not approve within 30 minutes, the registration is cancelled. In that case, start again from “Register PC...”.

## Credit

- “Credit: N% left” is shown under “AI” in Site settings.
- When no credit is left, the AI features cannot be used. Select “Open account page” and purchase more on the page that opens.
- The “Usage” table shows how many times and how much each user has used. The amount is a percentage of one credit purchase.

## Let editors use it

Admins can use the AI features once the PC is registered. Editors can use them only if an admin allows it.

1. Open the “Users” tab in the admin pages
2. Turn on “Can use AI” on the row of the editor

Everyone shares one credit balance. You can turn it on before registering the PC, but it takes effect only after the PC is registered.

## Have an AI collect links

Write what you want to collect for a group, and the AI collects matching pages from the web and lists them in the group.

### Make a group collect links

1. In the “Contents” tab of the admin screen, open the edit page of the group with “⋮” → “Edit”
2. Turn on “Collect links with AI”
3. In “What to collect”, describe the pages you want in your own words. If you have more than one topic, you can write them all
4. Select “Save”

### Collect and update

1. Open the group from the home screen
2. Select “Update” next to “Links collected by AI”

In a few seconds, the collected links appear below the contents of the group. Each update uses credit and replaces the links collected before. Links are not updated automatically.

- “Update” is shown only to people who can use the AI. Anyone who can see the group can see the collected links.
- You can also update from the “Contents” list of the admin screen: “⋮” on the group row → “Update the AI links”.

### Keep the links you want

Collected links are replaced when you update. Add the ones you want to keep to the group.

1. Select a collected link
2. Select “Add to this group”

The link stays in the group as an ordinary link. To remove it, delete the link in the admin screen.

### Stop collecting

Turn off “Collect links with AI” on the edit page of the group and save. The collected links are removed. The links you added stay.

## Unregister the PC

1. Open the “Site settings” tab in the admin pages and select “Unregister PC...” under “AI”
2. Select “Unregister”

After unregistering, the AI features can no longer be used on this PC. The credit stays in the account, and you can use it again by registering the PC again.

Removing the PC on the account page has the same effect.
