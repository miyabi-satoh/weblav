# Use the AI features

Some features let you ask an AI from inside WebLAV.

- Have an AI suggest the axes of an archive (→ [Set up an archive](06-archive-setup.md))
- Have an AI collect web links that match search keywords into a group (→ “Have an AI collect links” below)
- Ask an AI a question from any screen (→ “Ask AI” below)

To use them, an admin registers the computer that runs WebLAV with a “WebLAV account”. Each use of the AI consumes credit from the account. Creating an account is free.

## What is sent outside

Using the AI features sends the following outside the computer. Nothing is sent unless you use them.

- What is sent
  - When you ask for axes: the names of the folders and files in that archive
  - When you ask for links: the search keywords of that group
  - When you ask AI: the question you typed
- Where it is sent: the WebLAV account server (weblav.amiiby.com), and from there Google (Gemini) and Perplexity (web search)

> If the folder or file names of an archive include personal names or the like, check first whether they may be sent.

## Register the computer

An admin does this while the computer that runs WebLAV is connected to the internet.

1. Open the “Site settings” tab in the admin pages and select “Register computer...” under “AI”
2. Read what is sent outside, then select “Agree and start registering”
3. Scan the QR code with a smartphone, or select “Open in browser”
4. On the page that opens, sign in to your WebLAV account. If you have no account, enter your email address to create one
5. Check that the confirmation code on the page that opened matches the one shown in Site settings. If it differs, do not approve
6. Approve registering the computer

After you approve, the Site settings screen switches within a few seconds and shows the account's email address and the remaining credit.

To stop partway, select “Cancel”. If you do not approve within 30 minutes, the registration is cancelled. In that case, start again from “Register computer...”.

## Credit

- “Credit: N% left” is shown under “AI” in Site settings.
- When no credit is left, the AI features cannot be used. Select “Open account page” and purchase more on the page that opens.
- The “Usage” table shows how many times and how much each user has used. The amount is a percentage of one credit purchase.

## Let editors use it

Admins can use the AI features once the computer is registered. Editors can use them only if an admin allows it.

1. Open the “Users” tab in the admin pages
2. Turn on “Can use AI” on the row of the editor

Everyone shares one credit balance. You can turn it on before registering the computer, but it takes effect only after the computer is registered.

## Have an AI collect links

Give a group search keywords, and the AI collects matching pages from the web and lists them in the group.

### Make a group collect links

1. In the “Contents” tab of the admin pages, open the edit page of the group with “⋮” → “Edit”
2. Turn on “Collect links with AI”
3. In “Search keywords”, write the topics of the pages you want. If you have more than one topic, you can write them all
4. Select “Save”

### Collect and update

1. Open the group from the home screen
2. Select “Update” next to “Links collected by AI”

In a few seconds, the collected links appear below the contents of the group. Each update uses credit and replaces the links collected before. Links are not updated automatically.

- “Update” is shown only to people who can use the AI. Anyone who can see the group can see the collected links.
- You can also update from the “Contents” list of the admin pages: “⋮” on the group row → “Update the AI links”.

### Keep the links you want

Collected links are replaced when you update. Add the ones you want to keep to the group.

1. Select a collected link
2. Select “Add to this group”

The link stays in the group as an ordinary link. To remove it, delete the link in the admin pages.

### Stop collecting

Turn off “Collect links with AI” on the edit page of the group and save. The collected links are removed. The links you added stay.

## Ask AI

From any screen, you can send a question to the AI and get an answer. This is shown only to people who can use the AI.

1. Press the “Ask AI...” button at the bottom right of the screen. While a file or image is open, press the button in the bar at the top
2. Type in “Question” and press “Send”. You can also send with Ctrl+Enter (⌘+Enter on macOS)

The answer appears under “Answer”. Each question uses credit. Earlier questions and answers are not carried over, so when you follow up, include what the AI needs in the new question.

The panel opens beside the page or file (below it on narrow screens), so it does not cover it. You can move to other screens or files with the panel open.

## Unregister the computer

1. Open the “Site settings” tab in the admin pages and select “Unregister computer...” under “AI”
2. Select “Unregister”

After unregistering, the AI features can no longer be used on this computer. The credit stays in the account, and you can use it again by registering the computer again.

Removing the computer on the account page has the same effect.
