# Set up

Follow these steps on the computer that will run the server.

## 1. Install

### Windows

1. Search for “WebLAV” in Microsoft Store and select “Get”.
2. When installation finishes, select “Open”.

After you start WebLAV once, it starts automatically when you sign in. To stop this, turn off “Start at sign-in” from the WebLAV icon in the task tray.

### macOS

1. Put `WebLAV.app` in the Applications folder and open it.
2. When asked whether to allow incoming network connections, select “Allow”.

To start automatically, turn on “Start at login” from the WebLAV icon in the menu bar. If “Start at login (allow it in System Settings)” appears, select it, then turn on WebLAV in “Login Items”.

## 2. Create the first administrator

1. Choose “Setup” from the WebLAV icon in the task tray (menu bar on macOS).

   ![WebLAV icon menu in the task tray on Windows](images/quickstart-tray-menu.webp)

2. In the browser that opens, choose a username and password, then select “Create administrator”.

   ![The setup screen](images/quickstart-setup.webp)

3. Save or print the recovery code shown, then select “I've kept it”.

The recovery code lets you reset your password yourself if you forget it (→ [Sign in and display](03-account.md)).
It is shown only this once, so keep it where others can't see it.
The admin pages open after you select “I've kept it”.

If “This link cannot be used” appears, choose “Setup” again.

## 3. Open the admin pages

Select your username at the top right, then choose “Admin”.

![The username menu at the top right](images/setup-admin-menu.webp)

Next, go to [Add shared folders](04-roots.md).
