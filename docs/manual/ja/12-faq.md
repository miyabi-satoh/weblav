# よくある質問

## 家の外から見られますか

見られません。同じネットワークの中だけで使えます。

## NAS やほかのパソコンのフォルダを見せられますか

見せられません。WebLAV を動かしているパソコンにコピーしてください。

## 再生できない動画や音声があります

mp4 (H.264・AAC) と mp3 に変換すると、ほとんどの端末で再生できます。

## iPhone の写真が縮小画像で出ません

HEIC 形式の縮小画像は、WebLAV を動かしているパソコンが作ります。そのパソコンで HEIC を開けないと、縮小画像になりません。押して開けるのも、Safari など HEIC を表示できるブラウザだけです。
iPhone の「設定」→「カメラ」→「フォーマット」を「互換性優先」にすると、これから撮る写真は並ぶようになります。

## PDF や Word・Excel のファイルが縮小画像で出ません

動画や文書の縮小画像は、WebLAV を動かしているパソコンが作ります。作れないファイルは、アイコンのまま並びます。
Windows では、PDF は縮小画像を作れる PDF のアプリ (Adobe Acrobat Reader など) を入れたときだけ、Word と Excel は縮小画像を含めて保存したファイルだけ、縮小画像になります。Word・Excel では「名前を付けて保存」で「縮小版を保存する」にチェックを入れると含まれます。

## スマートフォンから登録や管理ができますか

できます。ログインすれば、ブラウザから操作できます。
ただし「公開できるフォルダ」の追加と最初の管理者の作成は、WebLAV を動かしているパソコンでしかできません。

## 見る人全員にアカウントが要りますか

要りません。「誰でも」のものは、ログインせずに見られます。
