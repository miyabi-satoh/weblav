# 安全に使うために

- 家庭や事務所など、知っている人だけがつなぐネットワークで使ってください。公共の Wi-Fi や、インターネットには出さないでください。
- Windows では、公共の Wi-Fi のネットワークを「プライベート」にしないでください。
- 見せる相手を絞りたいものは「要ログイン」にしてください。
- 「公開できるフォルダ」には、見せてよいフォルダだけを追加してください。`C:\` やユーザーのフォルダ全体は追加しないでください。
- 使わなくなったアカウントは削除してください。
- 管理者のパスワードは、ほかのサービスと同じものにしないでください。

通信を暗号化したいときは[詳しい設定](14-advanced.md) の「HTTPS で使う」を見てください。
