# 安全に使うために

- 家庭や事務所など、知っている人だけがつなぐネットワークで使ってください。公共の Wi-Fi や、インターネットには出さないでください。
- Windows では、公共の Wi-Fi のネットワークを「プライベート」にしないでください。
- 見せる相手を絞りたいものは「ログインした人」にしてください。
- 「共有」には、見せてよいフォルダーだけを追加してください。`C:\` やユーザーのフォルダー全体は追加しないでください。
- 共有の権限は、必要な人にだけ「追加のみ」「フルアクセス」にしてください。「フルアクセス」の人は、共有の中のファイルを消せます。
- 使わなくなったアカウントは削除してください。
- 管理者のパスワードは、ほかのサービスと同じものにしないでください。
- パスワードの最小文字数は、既定の 8 文字より短くしないでください。
- WebLAV を動かしているコンピューターは、インターネットにつなぎます。リンクを登録するときと一覧に出すときにリンク先からタイトルやカードの情報を取り、リンク先のファイル (PDF や動画など) を開くときはそのファイルを中継します。YouTube の動画は、見る人の端末が YouTube からじかに再生します。

通信を暗号化したいときは[詳しい設定](14-advanced.md) の「HTTPS で使う」を見てください。
