# はじめに

WebLAV は、コンピューターの中のファイルを、同じネットワークにいるスマートフォンやタブレットのブラウザーで見られるようにするアプリです。

![スマートフォンのブラウザーで WebLAV を開いた画面。登録したものの一覧・写真の一覧・写真を開いたところで、画面の下では音声が鳴っている](images/intro-overview.webp)

このマニュアルは、通知領域 (macOS はメニューバー、Ubuntu は画面右上) の WebLAV アイコンの「マニュアル」から、いつでも開けます。

## できること

- 音声を再生する
- 画像・PDF・動画・テキストを見る
- 外部サイトへのリンクを並べる
- ブラウザーから、コンピューターのフォルダーにファイルをアップロードする・名前を変える・動かす・消す
- 見せる相手を、誰でも・ログインした人だけ・自分だけに分ける

## しくみ

見る人の画面に出るのは、管理ページでコンテンツとして登録したものだけです。

![コンピューターのフォルダーと見る人の画面の関係。「学校」を共有に追加し、その中の「教材」と「英検」をフォルダーとして登録すると、見る人の画面にはこの2つだけが出る。登録していない「下書き」と、範囲の外の「家計簿」は出ない](images/how-it-works.webp)

- **共有**: WebLAV で扱ってよいフォルダーです。ログインした人は、権限に応じて中のファイルを見たり、足したり、動かしたりできます。追加しただけでは、ログインしていない人の画面には何も出ません。
- **コンテンツ**: 共有の中から、見せたいフォルダーを「フォルダー」として登録します。見る人の画面に出るのはこれです。

## クイックスタート

1. インストールして起動する。Windows は Microsoft Store で「WebLAV」を入手して開く、macOS は `WebLAV.app` を「アプリケーション」フォルダーに入れて開く

2. 通知領域 (macOS はメニューバー、Ubuntu は画面右上) の WebLAV アイコンから「セットアップ」を選び、管理者を作る。表示されたリカバリコードは保管しておく

   ![通知領域の WebLAV アイコンのメニュー (Windows)](images/quickstart-tray-menu.webp)

   ![セットアップの画面](images/quickstart-setup.webp)

3. 管理ページの「共有」で、見せてよいフォルダーを追加する。追加のボタンは、WebLAV を動かしているコンピューターで、通知領域のメニューの「ブラウザーで開く」から開いたときだけ出る (→ [共有を追加する](04-shares.md))

   ![共有の画面](images/quickstart-roots.webp)

4. 「コンテンツ」の「コンテンツを追加...」で「フォルダー」を選び、見せたいフォルダーを登録する

   ![コンテンツを追加するときの種類の選択](images/quickstart-add-folder.webp)

5. 画面右上の共有のアイコンを押して「QR コードを表示...」を選び、同じ Wi-Fi のスマートフォンで読み取る

   ![「このページを共有」の画面](images/share-qr.webp)

- 詳しい手順 → [設置する](02-setup.md)
- ほかの種類や公開範囲 → [コンテンツを登録する](06-register-content.md)
- 開けないとき → [うまくいかないとき](11-troubleshooting.md)
