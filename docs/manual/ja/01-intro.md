# はじめに

WebLAV は、パソコンの中のファイルを、同じネットワークにいるスマートフォンやタブレットのブラウザで見られるようにするアプリです。

![スマートフォンのブラウザで WebLAV を開いた画面。登録したものの一覧・写真の一覧・写真を開いたところで、画面の下では音声が鳴っている](images/intro-overview.webp)

このマニュアルは、通知領域 (macOS はメニューバー) の WebLAV アイコンの「マニュアル」から、いつでも開けます。

## できること

- 音声を再生する
- 画像・PDF・動画・テキストを見る
- 外部サイトへのリンクを並べる
- 見せる相手を、誰でも・ログインした人だけ・自分だけに分ける

## しくみ

見る人の画面に出るのは、管理画面でコンテンツとして登録したものだけです。

![パソコンのフォルダと見る人の画面の関係。「共有」を公開できるフォルダに追加し、その中の「教材」をフォルダとして、「英検」をアーカイブとして登録すると、見る人の画面にはこの2つだけが出る。登録していない「下書き」と、範囲の外の「家計簿」は出ない](images/how-it-works.webp)

- **公開できるフォルダ**: コンテンツを選べる範囲です。追加しただけでは、見る人の画面には何も出ません。
- **コンテンツ**: 公開できるフォルダの中から、見せたいフォルダを「フォルダ」や「アーカイブ」として登録します。見る人の画面に出るのはこれです。

## クイックスタート

1. インストールして起動する。Windows は Microsoft Store で「WebLAV」を入手して開く、macOS は `WebLAV.app` を「アプリケーション」フォルダに入れて開く

2. 通知領域 (macOS はメニューバー) の WebLAV アイコンから「セットアップ」を選び、管理者を作る。表示されたリカバリコードは保管しておく

   ![通知領域の WebLAV アイコンのメニュー (Windows)](images/quickstart-tray-menu.webp)

   ![セットアップの画面](images/quickstart-setup.webp)

3. 管理画面の「公開できるフォルダ」で、見せてよいフォルダを追加する。WebLAV を動かしているパソコンで、通知領域のメニューの「ブラウザで開く」から開いたときだけ出る (→ [公開できるフォルダを追加する](04-roots.md))

   ![公開できるフォルダの画面](images/quickstart-roots.webp)

4. 「コンテンツ」の「新規追加...」で「フォルダ」を選び、見せたいフォルダを登録する

   ![コンテンツを追加するときの種類の選択](images/quickstart-add-folder.webp)

5. 画面右上の QR コードのアイコンを押し、同じ Wi-Fi のスマートフォンで読み取る

   ![他の端末からつなぐの画面](images/quickstart-connect.webp)

- 詳しい手順 → [設置する](02-setup.md)
- ほかの種類や公開範囲 → [コンテンツを登録する](05-register-content.md)
- 開けないとき → [うまくいかないとき](11-troubleshooting.md)
