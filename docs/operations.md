# 操作の記録

利用者の操作を `operations` に残し、管理画面の「操作の記録」で新しい順に見せる (`GET /api/v1/admin/operations?before=&limit=&category=&userId=`、`AdminUser`)。誰がいつ何をしたかを、後から確かめるため。実装は `src/api/operations.rs`。

## 残すもの

利用者の操作のうち、データベース・共有の中・設定のファイルを書き換えるものと、ログインを残す。

| 分類 (`category`) | 操作 |
|---|---|
| `auth` | ログイン・ログアウト、自分のパスワードとユーザー名の変更、リカバリコードの作成、リカバリコードでの再設定 |
| `contents` | コンテンツの追加・編集・作成者の変更・削除、分類の追加・編集・削除・値の編集・インポート、再スキャン |
| `users` | ユーザーの追加 (最初の管理者を含む)・権限の変更・パスワードの再設定・名前の変更・削除 |
| `shares` | 共有の中のアップロード・新しいフォルダー・名前の変更・移動・コピー・削除・ホームに載せる (→ shares.md「共有の中の操作の記録」)、共有の追加・名前の変更・権限の変更・場所の選び直し・削除 |
| `settings` | ホームの表示・サーバーの設定・ログの設定の変更、バックアップのダウンロード、バックアップからの復元 |

- 見るだけの操作と、確かめるだけの要求 (プレビュー・事前の確かめ・パスワードの確かめ直し) は残さない。
- 自動で動く処理 (定期の再スキャン・リンクのプレビューの取り直しなど) は残さない。誰が何をしたかを確かめるためのもので、自動の処理の結果はログにある。
- ログインとリカバリコードでの再設定は、失敗も `failed` で残す。他人のアカウントで試されていないかを確かめるため。打ち込まれた名前をそのまま残し、その名前のユーザーがいれば `user_id` も入れる。試行の多さで断った分 (429) は、照合していないので残さない。
- 初めの設定の画面でバックアップから戻したものは残さない。操作した人がまだいないため。管理画面から戻したものは、戻した後のデータに書く。戻す前のユーザーの id は戻した後では別の人を指しうるので、名前だけを残す。
- 何も変えずに保存したもの (同じ値の編集・同じ権限への変更) は残さない。

## 1件に持つもの

- 誰が (`user_id`・`username`)、いつ、何をしたか (`op`)、結果 (`result`・`error`)。
- 対象 (`target_id`・`target_name`)。コンテンツ・ユーザー・共有で、名前はそのときの値を写す。消した後も読めるようにするため、外部キーは張らない。分類の操作は対象をアーカイブにし、分類の名前を `target_part` に持つ。
- 名前だけを変える操作 (ユーザー名・共有の名前の変更) は、変える前の名前を `target_name` に、変えた後の名前を `target_renamed_to` に持つ。
- 編集は、変えた項目を `fields` (JSON の配列。`operations::FieldChange`) に持つ。選択肢・数・名前のような短い値は、前と後の値も持つ (権限を何にしたか・題を何に変えたかを後から確かめるため)。説明・パターン・テンプレートのような長い文は名前だけにする。前後の全文を並べても、どこを変えたかは読み取れないため。パスワードとリカバリコードは、もともと編集の項目に入らない。
  - 場所 (`path`) は、画面と同じく共有の名前から先で持つ (→ folders.md「共有」)。
  - 共有の権限の例外は、人ごとに前と後を持つ (`subject` にその人の名前)。例外の無いほうは `null`。
- 操作した端末の IP アドレスを `client_ip` に持つ。同じ PC のリバースプロキシから来たときだけ、プロキシが `X-Forwarded-For` の最後に足した値を採る。LAN の端末が自分で付けた値は信じない。
- 共有の中の操作は、ほかに場所と件数を持つ (→ shares.md「共有の中の操作の記録」)。

## 書き方と残す期間

- 記録に失敗しても操作そのものは止めない (`record_or_warn`)。記録のために、済んだ操作を失敗に見せないため。
- 365 日より古い行は、起動したときと 1 日ごとに消す。1年前の同じ時期の出来事 (年度替わりの整理など) まで遡れるようにするため。
- 一覧は `before` (前の応答の `nextBefore`) で続きを読む。既定 100 件、上限 1000 件。
